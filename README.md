# ArkaSafe — сабақта отыру қалпын бақылау

Бір ультрадыбыстық датчикпен партада отырған оқушыға түзу отыруды еске салатын оқу прототипінің сайты. Next.js, TypeScript, Tailwind CSS, Recharts, Lucide React.

## Іске қосу

Node.js 20.9+ қажет.

```bash
npm install
npm run dev
```

http://localhost:3000

```bash
npm test
npm run build
npm start
```

## Негізгі принцип

1. Датчик тұрақты тірекке бекітіледі. Сұлбада ол орындық артынан оқушы арқасына бағытталған; нақты орнын тәжірибеде тексеру керек.
2. Оқушы түзу отырғанда бастапқы қашықтық калибрленеді.
3. Бір датчиктен ағымдағы қашықтық үздіксіз алынады.
4. `abs(distanceMm - baselineMm) > toleranceMm` болса, ауытқу басталады.
5. Ауытқу 3 секунд сақталса, экран, LED немесе buzzer түзу отыруды еске салады. Қалыпты ауқымға оралғанда ескерту тоқтайды.

Бір датчик барлық бағыттағы қисаюды анықтай алмайды. Ол тек өзінің өлшеу бағыты бойынша қашықтық өзгерісін байқайды. Медициналық диагноз немесе симметрия бағасы берілмейді. ±20 мм және 3 секунд — прототипке арналған тәжірибелік параметрлер.

## Демо қолдану

Бақылау → демо датчикке қосылу → бастапқы қашықтықты енгізу → бастапқы қалыпты сақтау (5 секунд) → бақылауды бастау. Калибрлеу демода енгізілген мәнді сақтайды; нақты датчиктен орташа мән алмайды.

Автоматты, бастапқы ауқымдағы, ұзақ ауытқу және қолмен өзгерту сценарийлері бар. Қолмен сценарийде ағымдағы қашықтықты өзгертіп, 3 секундтық ескертуді тексеруге болады. Дыбысты бақылауды бастамас бұрын қосыңыз. Жарамсыз көрсеткіш есепке алынбайды және үздіксіз ауытқу таймерін үзеді.

Бақылау сайт бөлімдері арасында ауысқанда жалғасады. Браузер қойындысы жасырын болса, өлшемдер алынбайды. Максимум 3600 өлшемнен кейін сеанс аяқталады. Қорытындыдағы пайыз — шек ішінде болған өлшемдер санының барлық өлшемге қатынасы; денсаулық бағасы немесе нақты уақыт үлесі емес. Сеанс ұзақтығы басталу мен аяқталу арасындағы уақытты, соның ішінде қойынды жасырын уақытты қамтиды.

Сеанс аяқталған соң «Сеансты сақтау» батырмасын басыңыз. localStorage кілті: `arqa-posture-sessions-v1`. Бұрынғы симметрия жазбалары жаңа тарихқа қосылмайды және жойылмайды. Тарих тек осы браузерде сақталады. Басып шығару / PDF батырмасы браузердің басып шығару диалогын ашады.

## ESP32 API

`POST /api/measurements`, `Content-Type: application/json`

```json
{
  "deviceId": "ARQASCAN-01",
  "distanceMm": 540,
  "baselineMm": 500,
  "toleranceMm": 20,
  "timestamp": "2026-09-05T12:00:00Z"
}
```

200: кіріс мәндері, `deviationMm: 40`, `withinRange: false`, `mode: "prototype"`, `saved: false`.
400: жарамсыз JSON, қашықтық (20–4000 мм), шек (5–200 мм), deviceId немесе уақыт, қазақша `error`.

API жеке өлшемді тексереді және бастапқы мәнмен салыстырады. Ол күй сақтамайды: 3 секундтық ескерту таймерін клиент немесе ESP32 жүргізуі керек. Нақты ESP32-ден сайтқа тікелей ағын, аутентификация және серверлік сақтау әлі қосылмаған. Демо толық дербес жұмыс істейді. Бұрынғы алты қашықтық өрісі қабылданбайды.

## Vercel

Репозиторийді импорттап, Next.js preset таңдаңыз. Build: `npm run build`. Қосымша environment variables немесе дерекқор қажет емес. API үшін серверлік Next.js ортасы қолданылады; static export қолданбаңыз.
